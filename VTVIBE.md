# Панель ИИ в f4 — быстрый старт

Это инструкция для тех, кто уже пробовал Google AI Studio в браузере
и хочет то же самое прямо в файловом менеджере, **бесплатно и не привязывая карту**.

Всё займёт минуты три. Ничего доустанавливать не нужно.

---

## Коротко: как это устроено

Панель ИИ в f4 — это **обычная панель с файлами**. Просто вместо диска на ней
лежит диалог с моделью.

Значит, никаких новых клавиш учить не надо:

* **F5** с левой панели на правую — «покажи модели вот этот файл»;
* **F5** обратно — «забери то, что модель написала»;
* **F3** — почитать; **F4** — поправить;
* **F8** — убрать из диалога.

Вопрос печатается в командной строке внизу, после `ai:`.

---

## Шаг 1. Взять бесплатный ключ (2 минуты)

1. Откройте **https://aistudio.google.com/apikey**
2. Войдите обычным гугл-аккаунтом (тем же, что и в почте).
3. Нажмите **Create API key** (создать ключ).
4. Скопируйте появившуюся строку. Она начинается на `AIza...`

Всё. Карту вводить не просят, счёт не выставят: пока вы не включили
биллинг вручную, работает бесплатный лимит, а при его исчерпании запросы
просто перестают проходить до следующего дня.

> Ключ — это как пароль. Никому не показывайте и не выкладывайте в чужие чаты.

---

## Шаг 2. Отдать ключ файловому менеджеру

Запустите f4 и наберите в командной строке внизу:

```
ai:key
```

Появится окошко — вставьте туда ключ и нажмите Enter.
Дальше спросят модель — просто нажмите Enter ещё раз, чтобы оставить как есть.

Ключ сохранится в файл `vtvibe.ini` в папке настроек f4, доступный только вам.

**Если предпочитаете переменные окружения** — можно вообще ничего не вводить,
f4 сам подхватит `GEMINI_API_KEY`:

```
export GEMINI_API_KEY=AIza...
```

---

## Шаг 3. Проверить, что всё живо

Наберите:

```
ai:models
```

Через пару секунд появится список моделей, до которых дотягивается ваш ключ.
Если список появился — всё работает.

Названия моделей у Google меняются несколько раз в год, поэтому **правильный
способ узнать актуальное имя — вот эта команда**, а не статья в интернете.
Понравилась какая-то из списка — переключитесь:

```
ai:model gemini-3.6-flash
```

(подставьте то имя, которое реально показал `ai:models`;
для бесплатного лимита берите модели со словом `flash` — они самые щедрые)

---

## Шаг 4. Первый диалог

1. Нажмите **Ctrl+Alt+A** — на второй панели откроется диалог с моделью.
   (то же самое: **Alt+F1** / **Alt+F2** → пункт **AI** в списке дисков)
2. Зайдите на панели диалога в папку **`ctx`** (Enter на ней).
3. Перейдите **Tab**'ом на панель с вашими файлами, встаньте на нужный файл
   или папку и нажмите **F5**. Файл уехал в контекст — теперь модель его видит.
4. Наберите внизу вопрос:

```
ai: что делает этот файл и что в нём не так?
```

Пойдёт полоска прогресса (её всегда можно прервать кнопкой Cancel),
а ответ откроется в обычной смотрелке f4. Esc — выйти.

Дальше можно спрашивать ещё: модель помнит предыдущие вопросы и ответы.

---

## Шаг 5. Забрать результат

Вся переписка лежит файлами, её можно листать и перечитывать:

| Где | Что лежит |
| --- | --- |
| `ctx/` | то, что вы дали модели. Убрать — **F8** |
| `chat/` | история: по файлу на каждое сообщение |
| `out/` | целые файлы, которые выдала модель |
| `draft.md` | черновик длинного вопроса |
| `session.md` | текущие настройки и подсказки по клавишам |

Если модель написала целый файл, он появится в **`out/`**.
Встаньте на него, **F3** — посмотреть, **F5** — положить к себе на диск.

**Длинный вопрос** удобнее писать в редакторе: **F4** на `draft.md`,
пишете сколько нужно, **F2** — сохранить, потом наберите просто `ai:`
(двоеточие и ничего после него) — уедет содержимое черновика.

---

## Все команды

| Команда | Что делает |
| --- | --- |
| `ai: ваш вопрос` | спросить модель |
| `ai:` | отправить `draft.md` |
| `ai:models` | список доступных моделей |
| `ai:model ИМЯ` | сменить модель |
| `ai:key` | ввести ключ доступа |
| `ai:new` | начать диалог с чистого листа (файлы в `ctx/` останутся) |
| `ai:help` | эта шпаргалка |

Плюс пункты в меню **F9 → Команды** и клавиша **Ctrl+Alt+A**.

---

## Если что-то пошло не так

**«Ключ доступа не найден»** — не выполнен шаг 2. Наберите `ai:key`.

**Ошибка со словами `models/... is not found`** — имя модели устарело.
Наберите `ai:models` и возьмите любое имя из списка.

**Ошибка `HTTP 429`** — упёрлись в бесплатный лимит (он считается на минуту
и на сутки). Подождите минуту и повторите; f4 сам делает несколько попыток.
Если повторяется часто — возьмите модель полегче, со словом `flash-lite`.

**Ошибка `HTTP 400`** — обычно слишком много всего в `ctx/`.
Уберите лишнее клавишей **F8**.

**Ответ приходит долго** — это нормально для большого контекста.
Нажмите Cancel в окне прогресса, если передумали ждать.

---

## Что вообще уезжает в интернет

Только то, что вы сами положили в `ctx/`, плюс текст ваших вопросов.
Больше ничего: ни ваш диск целиком, ни соседние папки.
Посмотреть глазами, что там лежит, можно всегда — это обычные файлы.

Файлы, похожие на секреты (`.env`, `id_rsa`, `*.pem`, `credentials`, всё из `.ssh`),
**не отправляются вообще**, даже если случайно попали в `ctx/` —
вместо содержимого модель увидит только строчку о том, что файл пропущен.

И имейте в виду: на бесплатном лимите Google оставляет за собой право
использовать переписку для улучшения своих продуктов. Для рабочих секретов
это не место — берите платный тариф или локальную модель.

---

## Не только Google

Панель говорит на общепринятом протоколе, поэтому её можно направить
куда угодно. Файл `vtvibe.ini` в папке настроек f4:

```ini
[general]
base_url = https://generativelanguage.googleapis.com/v1beta/openai
model    = gemini-3.6-flash
key      = AIza...
```

Другие варианты — поменяйте `base_url` и `model`:

* **OpenRouter** — `https://openrouter.ai/api/v1` (там есть бесплатные модели)
* **Ollama** — `http://127.0.0.1:11434/v1`, ключ не нужен вовсе
* **LM Studio** — `http://127.0.0.1:1234/v1`, ключ не нужен вовсе

Локальные модели — это полностью бесплатно и никуда не уходит из дома.

## In English

The AI panel mounts a model's context as an ordinary drive, so the usual
keys keep their meaning: **F5** copies a file into the dialog, **F5** copies
the model's answer back to disk, **F3**/**F4** read and edit, **F8** drops.

Getting started with the free Google AI Studio tier:

1. Get a key at https://aistudio.google.com/apikey (no credit card required).
2. In f4, type `ai:key` in the command line and paste it.
3. Type `ai:models` to see which models the key can reach, then
   `ai:model <name>` to pick one. Model names change often — ask the command,
   not the documentation.
4. Press **Ctrl+Alt+A**, copy a file into `ctx/` with **F5**, then ask:
   `ai: what does this file do?`

The dialog lives in `chat/`, whole files written by the model land in `out/`,
and `draft.md` is there for long prompts (**F4**, **F2**, then a bare `ai:`).
Settings are in `vtvibe.ini` in the f4 config directory; the key is also read
from `GEMINI_API_KEY`. Point `base_url` at OpenRouter, Ollama or LM Studio to
use anything else.
