# you fix the line.

# All entries come from the first full run of the check over help/*.hlf
# (2026-08-10). The lang/*.lng files are already clean and deliberately absent
# from this list. Two kinds of damage are mixed together below.
#
# A. The ASCII letter "x" used as the dimension separator, as in
#    WIDTHxHEIGHT, glued to two words of a non-Latin script. Harmless on
#    screen, but it is the same shape as the real defect and it makes the
#    string unsearchable in its own language. Fix: U+00D7 MULTIPLICATION SIGN.
#    Affected: be:229, hi:250, hy:234, ka:233, ru:241, uk:233.
#
# B. Genuine look-alike damage: one letter of a word silently replaced by its
#    twin from another alphabet (Hebrew vav -> Arabic waw, Latin "ri" inside a
#    Hebrew word, Cyrillic "ма" ending a Latvian one, a Greek "πα" inside the
#    Lithuanian "pas-" prefix, Devanagari inside Bengali). Fix: put the native
#    letter back, do not retranslate the string. Everything else below.
#
