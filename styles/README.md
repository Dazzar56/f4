1. Файлы, начинающиеся на точку, красятся в бирюзовый
2. Сделать такую тему для colorer
3. Белый на персиковом, когда выделена папка, плохо читается
4. Оранжевый верх в редакторе отвлекает от пользовательских данных. Надо использовать там цвета кейбара. И в просмотрщике тоже.
5. Выделить всё на панели и см. её низ
6. Статистика по выделенным на панели файлам - контраст слишком низкий.
