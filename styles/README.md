

Fonokai

Кроссовер Monokai и вайба «старое радио». Продолжение идей Default Dark из far2l с уходом в теплоту.
И ещё лёгкая настольгическая отсылка к оранжевым монохромным мониторам.

Основные акценты: янтарный (#e6b450), тёмное дерево (#37322c), бумага (#dbd3c4).
